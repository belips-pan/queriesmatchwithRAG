# 🧠 Multilingual & Multi-Format RAG Engine

Ένα ελαφρύ, γρήγορο και αυτόνομο σύστημα **Retrieval-Augmented Generation (RAG)** με υποστήριξη ελληνικής γλώσσας, σχεδιασμένο για αναζήτηση και εξαγωγή πληροφοριών από έγγραφα πολλαπλών τύπων (`.pdf`, `.docx`, `.txt`).

Το σύστημα συνδυάζει **NLP (spaCy)**, **συνωνυμικά λεξικά**, **line-aware chunking** και **ευρετικά μοντέλα βαθμολόγησης (heuristics)** για να εντοπίζει με ακρίβεια όχι μόνο το κατάλληλο τμήμα του κειμένου (Chunk), αλλά και την **ακριβή απάντηση** (Sentence/Exact Match).

---

## 📸 Βασικά Χαρακτηριστικά (Features)

* **Multi-Format Document Parsing:** Υποστήριξη και αυτόματη ανάγνωση αρχείων `.pdf`, `.docx` και `.txt`.
* **Greek NLP & Lemmatization:** Χρήση του γλωσσικού μοντέλου `el_core_news_sm` του spaCy για λημματοποίηση (αφαίρεση κλίσεων) και αναγνώριση μερών του λόγου (POS Tagging).
* **Smart Line-Aware Chunking:** Έξυπνος καταμερισμός του κειμένου που σέβεται τις αλλαγές παραγράφων και γλωσσαρίων, εμποδίζοντας το «σπάσιμο» των ορισμών στη μέση.
* **Intent Recognition & Glossary Priority:** Αναγνώριση ερωτημάτων ορισμού (π.χ. *«Τι σημαίνει X;»*, *«Ορισμός του Y»*) με αυτόματη απόδοση έξτρα πριμ (bonus scoring) σε τμήματα κειμένου που περιέχουν ορισμούς ή γλωσσάρια.
* **Semantic & Synonym Matching:** Υποστήριξη αμφίδρομης αναζήτησης με συνώνυμα και ξενόγλωσσους όρους (π.χ. `AUC` ↔ `Εμβαδόν Κάτω από την Καμπύλη`).
* **Dual Output Mode:** Εμφάνιση τόσο της **συγκεκριμένης πρότασης/απάντησης** (Exact Match) όσο και του **πλήρους πλαισίου** (Full Chunk Context).

## ⚖️ Πλεονεκτήματα & Μειονεκτήματα

### 🟢 Πλεονεκτήματα
1. **100% Local & Free:** Δουλεύει τοπικά στον υπολογιστή χωρίς την ανάγκη εξωτερικών API keys (OpenAI, Anthropic κ.λπ.) ή συνδρομών.
2. **Zero Hallucinations:** Επιστρέφει **αποκλειστικά** αυτούσια τμήματα του εγγράφου, εξαλείφοντας τον κίνδυνο παραγωγής ψευδών πληροφοριών.
3. **Υψηλή Ταχύτητα:** Εκτελείται σε κλάσματα του δευτερολέπτου ακόμα και σε απλούς επεξεργαστές (CPU) χωρίς απαίτηση για GPU.
4. **Εξειδίκευση στα Ελληνικά:** Αντιμετωπίζει αποτελεσματικά τις ιδιαιτερότητες της ελληνικής γλώσσας (πτώσεις, πολυτονικό/μονοτονικό, ξενόγλωσσοι όροι).

### 🔴 Μειονεκτήματα
1. **Keyword/Lexical Based:** Βασίζεται σε λεξική και συνωνυμική αναζήτηση (όχι σε Vector Embeddings), επομένως μπορεί να χάσει πολύ αφηρημένες παραφράσεις αν δεν υπάρχουν στο λεξικό συνωνύμων.
2. **Manual Synonym Dictionary:** Για πολύ εξειδικευμένους τομείς (π.χ. ιατρική, νομικά), το λεξικό συνωνύμων χρειάζεται χειροκίνητο εμπλουτισμό.
3. **Static Chunking Size:** Το μέγεθος των chunks είναι σταθερό (προκαθορισμένο όριο χαρακτήρων) και ενδέχεται να απαιτεί προσαρμογή ανάλογα με τη δομή του εγγράφου.

## 🛠️ Απαιτήσεις System & Εγκατάσταση

### 1. Προαπαιτούμενα
* Python 3.9 ή νεότερη
* Pip

### 2. Εγκατάσταση Βιβλιοθηκών

Ανοίξτε το τερματικό (Command Prompt / Terminal) και εκτελέστε:

```bash
pip install spacy pypdf python-docx
```

(Σημείωση: Το ελληνικό μοντέλο el_core_news_sm της spacy κατεβαίνει ξεχωριστά μετά την εγκατάσταση των requirements με την εντολή


```bash
python -m spacy download el_core_news_sm
```

).
